# IT Support Guide (IT-GUIDE-002)

## How to raise a ticket
Use the ServiceDesk portal or the `/ticket` command in Teams. Each ticket gets an ID like **INC-12345**.

## Priorities and SLAs
| Priority | Example | First response | Resolution target |
|---|---|---|---|
| P1 | Production outage, security incident | 15 minutes | 4 hours |
| P2 | Team blocked, VPN down for a group | 1 hour | 1 business day |
| P3 | Single user issue, software install | 4 hours | 3 business days |
| P4 | Request / question | 1 business day | 5 business days |

## Common fixes
- VPN fails to connect: restart the GlobalConnect client, then re-enter MFA. If still failing, raise a P3.
- Password reset: self-service at reset.acme.example; requires MFA.
- New software requests need manager approval and take up to 3 business days.
