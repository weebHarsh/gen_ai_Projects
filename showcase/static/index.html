Models and providers

One interface over Claude and a set of free and paid providers. Add a key and a provider joins the routing chain.

How routing works

quick → Haiku

Short single-fact lookups. Cheapest and fastest.

default → Sonnet

Normal policy questions and every agent turn, since tool calling has to be reliable.

complex → Opus

Multi-document comparisons and conflict analysis.

The router classifies the question and picks a tier. Each tier maps to a model on every provider. If the chosen provider is rate-limited or errors, the call falls through to the next configured provider and the trace records a fallback span. Picking a provider yourself skips routing.

Golden-set eval

Source hit rate is how often the retriever's top results include the document that holds the answer. Refusal rate is how often out-of-scope questions get an honest "I don't know". Citation rate is how often answers cite a source. The offline project adds Ragas and DeepEval for faithfulness and answer relevance, which need an LLM judge and run outside this page.

What to say

  • Routing picks Haiku, Sonnet or Opus per question, so cost follows difficulty.
  • Providers fall through a chain, and the app degrades to retrieval-only instead of failing.
  • The agent pauses for human approval before any action that changes state.
  • Every request carries a trace, so latency and token spend are visible per step.
  • A golden-set eval gates changes, and the offline suite adds Ragas and DeepEval.
Acme Corp is a fictional company. All policy text is sample data.
